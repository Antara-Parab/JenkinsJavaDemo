## Reporting a Vulnerability

We take the security of this project seriously. If you discover a vulnerability or security risk, please report it privately:

- **Email:** parabantara05@gmail.com
- Please provide a detailed description of the vulnerability, including steps to reproduce and any potential impact.
- We will acknowledge receipt of your report within 48 hours and work expeditiously toward a resolution.
